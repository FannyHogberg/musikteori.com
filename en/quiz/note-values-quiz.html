Notes and Note Values Quiz

Can you recognize whole notes, half notes, quarter notes, eighth notes and sixteenth notes?

About this quiz

This quiz tests how well you know the most common note values: whole notes, half notes, quarter notes, eighth notes and sixteenth notes. You will identify notes from pictures, work out how many quarter notes or eighth notes fit into a longer note, and answer questions about note heads, stems and flags. Some questions are listening questions where you hear a note value played against a steady beat.

Each round has 8 random questions drawn from a bank of 26, so the quiz is different every time. You need 60% correct to pass, and when you are done you can review your answers to see which ones were right and wrong.

Want to brush up first? Read Part 6: Note Values in the course Music Theory from Scratch.
