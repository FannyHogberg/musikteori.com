Part 7: Rests

Now you know note values and how long different notes should sound. But music does not consist only of sound - sometimes there should be silence too!

What is a rest?

A rest indicates that you should be silent and not play.

Just like notes, rests can have different lengths. The shape of the rest shows how long you should be silent.

Whole rest

The whole rest looks like a filled rectangle hanging below a line in the staff.

The whole rest corresponds to a whole note - that is, silence for 4 beats.

Half rest

The half rest looks almost the same as the whole rest, but sits on top of a line instead.

The half rest corresponds to a half note - that is, silence for 2 beats.

Remember: Think of the whole rest as heavy, so it hangs below the line. The half rest sits on top.

Quarter rest

The quarter rest looks a bit different - somewhat like a lightning bolt.

The quarter rest corresponds to a quarter note - that is, silence for 1 beat.

Eighth rest

The eighth rest looks a bit like a seven with a hook.

The eighth rest corresponds to an eighth note - that is, silence for half a beat.

Sixteenth rest

The sixteenth rest looks like the eighth rest, but has two hooks instead of one.

The sixteenth rest corresponds to a sixteenth note - that is, silence for a quarter of a beat.
