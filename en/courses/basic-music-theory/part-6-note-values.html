Part 6: Note Values

Now you know where the notes are placed in the staff. But when reading sheet music you also need to know how long each note should be played.
That is what we are going to learn now - note values!

In this lesson we count the quarter note as one beat.

Quarter note

Many people probably recognise this note. It is called a quarter note.

It has a filled note head (solid black) and a stem.

The quarter note lasts for 1 beat.

Half note

The half note looks almost like a quarter note, but the note head is open (hollow) instead of filled.

The half note lasts for 2 beats.

Whole note

The whole note has an open note head (an oval ring) and no stem.

The whole note lasts for 4 beats.

Eighth note

Now we go the other way - notes that are shorter than a quarter note.

The eighth note looks like a quarter note, but has a flag on the stem.

Two eighth notes fit into one beat.
